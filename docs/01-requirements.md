# Requirements

## Functional Requirements

### Authentication

**FR-001** : Users can link mobile numbers <br>

**FR-002** : Users must link their names

### Dashboard

**FR-003** : Display the various [types of emergencies](/docs/00-product-vision.md#types-of-emergencies) <br>

### Reporting

**FR-004** : Application should get the current device's  location when submitting a report

## Non-Functional Requirements

**NFR-001** : App launches under 2 seconds. <br>
**NFR-002** : Supports Android and iOS.
