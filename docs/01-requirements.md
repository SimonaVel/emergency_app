# Requirements

## Functional Requirements

### Authentication

FR-001 - Users can link mobile numbers
FR-002 - Users must link their names

### Dashboard

FR-002 - Display the various types of emergencies

### Reporting
FR-003 - Application should get the current device's  location when submitting a report

## Non-Functional Requirements

NFR-001 - App launches under 2 seconds.
NFR-002 - Supports Android and iOS.
