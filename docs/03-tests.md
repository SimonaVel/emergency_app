# Tests

## Technologies

**flutter_test** dependency - for unit & integration tests
&ensp;*why?*<br>
&ensp;&ensp; standard choice for flutter apps.

**Vitest** - for backend api testing <br>
&ensp;*why?*<br>
&ensp;&ensp;It does not need a running server -> faster

**Playwright** - for system testing <br>
&ensp;*why?*<br>
&ensp;&ensp;Industry standard. <br>

## Execution
| Tech                      | Command                    |
| ------------------------- | -------------------------- |
| flutter_test              | ```flutter test```         |
| Vitest                    | ```npm run backend:test``` |
| Playwright                | ```npx playwright test```  |
